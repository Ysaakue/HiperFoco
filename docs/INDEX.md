# Índice de requisições

Cada pasta `REQ<NNN>-<slug>/` reúne o planejamento e as evidências de QA de uma requisição (feature, melhoria ou investigação). Estrutura padrão de cada pasta:

- `planning.md` — contexto, decisões e roadmap da demanda
- `qa/` — documentos de ciclo de testes (`M{n}-test-cycle.md` ou equivalente), gate de aprovação por etapa
- `ref/` — material de referência usado no planejamento (screenshots, links, briefings). Não versionado (ver `.gitignore`)
